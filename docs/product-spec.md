# WaveShare 產品規格書

**產品目的：** 讓浪友把一趟衝浪的影片與心得記在一起，日後能按日期、浪點或浪板回顧。

本文的「現況」以編寫時的主分支（`77c54ca`）為準；[PR #1](https://github.com/ChristingChang/waveshare/pull/1) 和 [PR #2](https://github.com/ChristingChang/waveshare/pull/2) 是尚未合併的變更，不代表正式網站已上線。 [回文件首頁](README.md)

## 誰能使用

| 角色         | 可以做什麼                                                                     |
| ------------ | ------------------------------------------------------------------------------ |
| 未登入的訪客 | 開啟網站會被導往登入，無法進入日誌或好友頁。獨立的影片網址是另一回事，見下方。 |
| 已登入的浪友 | 新增、回看、編輯和刪除自己的紀錄；也能搜尋其他浪友和管理收到的邀請。           |
| 好友         | 可以在好友名單看見彼此；不會因此取得對方的紀錄、影片或統計。                   |

現況使用 Manus 帳號登入。PR #2 改用 GitHub，並加入 TiDB Cloud 連線設定；第一次用 GitHub 登入不會自動接回舊 Manus 帳號的紀錄。

## 主要功能

| 功能             | 現況                                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新增紀錄         | 選一段影片、日期和浪點，給 1 至 5 顆星的浪況評分（預設 3 顆）；浪板類型與心得可不填。影片傳成功後才送出紀錄，存好會回首頁。                       |
| 回看、編輯、刪除 | 詳細頁可播放影片。可修改日期、浪點、評分、浪板與心得，但編輯畫面不能替換影片。刪除前會確認；現況只刪日誌，影片檔仍留在儲存服務。                  |
| 首頁與日曆       | 首頁有最近三筆紀錄和統計摘要；日曆標示有紀錄的日期，點選可打開當日的紀錄。                                                                        |
| 地圖             | 顯示台灣浪點，依本人的紀錄標示是否造訪和次數。程式清單有 37 個浪點。                                                                              |
| 統計             | 顯示個人的衝浪次數、浪點數量、平均浪況評分、常去浪點與浪板使用次數。                                                                              |
| 好友             | 可用名字或 Email 找浪友，送出邀請、接受或拒絕收到的邀請。搜尋結果會顯示對方的 Email（若有）。不能移除好友、取消已送出的邀請，或在被拒後重新邀請。 |

## 影片與隱私

**日誌只有本人能讀，不等於影片是私密的。** WaveShare 用影片網址直接播放。現況由 Manus Forge 產生的舊網址是否公開或會到期，未確認；PR #1 的 R2 播放網址是公開的，知道網址的人不用登入，也不必是好友。10 分鐘的期限只限上傳網址，不限播放網址。

| 規則       | 現況                                                         | PR #1                                                                                                                                   |
| ---------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| 支援格式   | 後端辨識 MP4、MOV、WebM 的檔頭。                             | 檢查申報格式為 MP4、MOV 或 WebM；不掃描影片內容。                                                                                       |
| 大小       | 程式上限 100 MiB；在 Vercel 會先受整筆請求約 4.5 MB 的限制。 | 單檔最多 100 MiB，直接傳到 R2，不受上述 Vercel 請求大小限制。                                                                           |
| 次數       | 未實作 WaveShare 每日上傳次數限制。                          | 每位使用者在任意連續 24 小時內最多申請 10 次；沒傳完也算。                                                                              |
| 刪除與清理 | 刪除紀錄不會刪影片檔。                                       | 如果沒有其他紀錄在用，會嘗試刪除 R2 影片；失敗不阻擋日誌刪除。可另外設定排程清理長時間未被引用的上傳。舊 Forge 影片不會自動刪除或搬遷。 |

未提供轉檔，能否播放仍取決於瀏覽器與影片編碼。

## 目前不在範圍

- 未提供好友觀看日誌、動態牆、逐筆分享或私密影片播放。
- 同行夥伴只有預留資料結構，還沒有可用的標記功能。
- 舊資料是否搬遷、用戶如何接續舊帳號，以及影片是否應改為私密播放，見[架構決策紀錄](architecture-decisions.md)。

想知道每一步怎麼走，請看[流程圖](flows.md)；想逐項驗收，請看[使用者故事](user-stories.md)。
