# WaveShare 產品規格書

**產品目的：** 讓浪友把一趟衝浪的影片與心得記在一起，日後能按日期、浪點或浪板回顧。

本文的「現況」以編寫時的主分支（`ae2c061`）為準，不代表正式網站已部署或驗證。[回文件首頁](README.md)

## 誰能使用

| 角色         | 可以做什麼                                                                     |
| ------------ | ------------------------------------------------------------------------------ |
| 未登入的訪客 | 開啟日誌或好友頁會被導往 Google 登入，看不到內容，也不能播放影片。隱私權政策和服務條款不需登入。 |
| 已登入的浪友 | 新增、回看、編輯和刪除自己的紀錄；也能搜尋其他浪友和管理收到的邀請。           |
| 好友         | 可以在好友名單看見彼此；不會因此取得對方的紀錄、影片或統計。                   |

WaveShare 使用 Google 帳號登入，不再需要 Manus。第一次用 Google 登入會建立新的 WaveShare 帳號；即使電子郵件相同，也不會自動接回舊 Manus 帳號的日誌或好友。之後用同一個 Google 帳號登入，就會回到同一個 WaveShare 帳號。WaveShare 只儲存 Google 已驗證的電子郵件地址。

部署時可用 TiDB Cloud 保存帳號、好友和日誌；影片檔另存 Cloudflare R2。設定方式見[部署教學](DEPLOY.zh-TW.md)。

## 主要功能

| 功能             | 現況                                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新增紀錄         | 選一段影片（MP4、MOV 或 WebM，最多 100 MiB）、日期和浪點，給 1 至 5 顆星的浪況評分（預設 3 顆）；浪板類型與心得可不填。影片直接傳到 R2，傳成功後才送出紀錄，存好會回首頁。 |
| 回看、編輯、刪除 | 詳細頁可播放影片。可修改日期、浪點、評分、浪板與心得，但編輯畫面不能替換影片。編輯時會帶出原本的地區和浪點，只改評分或心得也能直接儲存；只有改選地區時才要重選浪點。刪除前會確認；若沒有其他紀錄使用同一支 R2 影片，會一併嘗試刪除影片檔。 |
| 首頁與日曆       | 首頁有最近三筆紀錄和統計摘要；日曆標示有紀錄的日期，點選可打開當日的紀錄。                                                                        |
| 地圖             | 顯示台灣浪點，依本人的紀錄標示是否造訪和次數。程式清單有 37 個浪點。                                                                              |
| 統計             | 顯示個人的衝浪次數、浪點數量、平均浪況評分、常去浪點與浪板使用次數。                                                                              |
| 好友             | 只能用名字找浪友，搜尋結果不顯示電子郵件地址。可送出邀請，也可接受或拒絕收到的邀請。不能移除好友、取消已送出的邀請，或在被拒後重新邀請。 |

## 影片與隱私

**影片和日誌一樣，只有本人能看。** 影片網址是 WaveShare 自己的 `/api/videos/<紀錄編號>`；每次播放，WaveShare 都會先確認登入的是紀錄本人，才給一個 15 分鐘有效的 R2 播放連結（[PR #10](https://github.com/ChristingChang/waveshare/pull/10)）。未登入的人和其他帳號（包括好友）都打不開。Cloudflare 上的 R2 公開存取必須關閉，舊的公開網址才會失效。PR #1 之前由 Manus Forge 產生的舊網址，從 WaveShare 只有本人能打開，但原網址本身是否公開，未確認。

| 規則       | 現況                                                                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 支援格式   | 只接受申報為 MP4、MOV 或 WebM 的影片；不掃描影片內容。                                                                                                                 |
| 大小       | 單檔最多 100 MiB，由瀏覽器直接傳到 R2，不受 Vercel 約 4.5 MB 的請求大小限制。                                                                                          |
| 次數       | 每位浪友在任意連續 24 小時內最多申請 10 次上傳；沒傳完也算。達上限時畫面會提示稍後再試。                                                                               |
| 播放       | 只有本人能播放。播放連結 15 分鐘後失效；播放途中過期時，播放器會自動重新取得一次並接著播。上傳網址的 10 分鐘期限與播放無關。 |
| 刪除與清理 | 刪除紀錄時，若沒有其他紀錄在用，會嘗試刪除 R2 影片；失敗不阻擋日誌刪除。管理者可另外啟用每日清理，處理超過 24 小時仍沒存成紀錄的上傳。舊 Forge 影片不會自動刪除或搬遷。 |

未提供轉檔，能否播放仍取決於瀏覽器與影片編碼。

## 目前不在範圍

- 未提供好友觀看日誌或影片、動態牆或逐筆分享。
- 同行夥伴只有預留資料結構，還沒有可用的標記功能。
- 舊資料是否搬遷、用戶如何接續舊帳號，見[架構決策紀錄](architecture-decisions.md)。

想知道每一步怎麼走，請看[流程圖](flows.md)；想逐項驗收，請看[使用者故事](user-stories.md)。
