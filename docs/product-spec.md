# WaveShare 產品規格書

**產品目的：** 讓浪友把一趟衝浪的浪況、心得與選填的影片或照片記在一起，日後能按日期、浪點或浪板回顧，也能在站內分享紀錄給指定好友，或下載圖卡分享到站外。

本文的「現況」以編寫時的主分支為準，不代表正式站已部署或驗證。[回文件首頁](README.md)

## 誰能使用

| 角色         | 可以做什麼                                                                     |
| ------------ | ------------------------------------------------------------------------------ |
| 未登入的訪客 | 開啟網站或直接打開日誌、好友等頁面時，先看到介紹頁。可看浪況、照片背景的分享圖卡，以及衝浪紀錄、日曆和統計的示範，也可開啟隱私權政策和服務條款；看不到實際的紀錄、影片或照片。開啟浪友邀請連結則會進入邀請頁。 |
| 已登入的浪友 | 新增、回看、編輯和刪除自己的紀錄；也能搜尋其他浪友和管理收到的邀請。可從頁面上方登出。 |
| 好友         | 只可查看對方選擇分享的那幾筆紀錄及其影片和照片，不能修改，也看不到對方的個人統計。 |

介紹頁以「每一道浪，都值得留下。」為主標題。第一個「使用 Google 登入」按鈕下方的浪況是示範，不是即時預報；網站只會依浪點與日期帶入可取得的資料。「你決定誰看得到」說明紀錄預設只給自己看，也可逐筆分享給指定好友。照片背景的圖卡同樣是示範；把圖片傳出去不會開放日誌。

把網站網址貼到支援連結預覽的平台時，預覽使用網站提供的固定封面，不含個人的日誌資料。即使浪友邀請連結用了同一張封面，點開仍會前往邀請頁，不會被換成網站首頁。

在介紹頁按「使用 Google 登入」才會前往 Google；登入成功後回到 WaveShare 首頁。登出成功後，畫面顯示介紹頁，不會自動再次登入；登出失敗會顯示提示。瀏覽器分頁標題是「WaveShare 浪旅誌」，圖示是海浪。

WaveShare 使用 Google 帳號登入，不再需要 Manus。第一次用 Google 登入會建立新的 WaveShare 帳號；即使電子郵件相同，也不會自動接回舊 Manus 帳號的日誌或好友。之後用同一個 Google 帳號登入，就會回到同一個 WaveShare 帳號。WaveShare 只儲存 Google 已驗證的電子郵件地址。

部署時可用 TiDB Cloud 保存帳號、好友和日誌；影片和照片檔另存 Cloudflare R2。設定方式見[部署教學](DEPLOY.zh-TW.md)。

## 主要功能

| 功能             | 現況                                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新增紀錄         | 選日期和浪點，給 1 至 5 顆星的浪況評分（預設 3 顆）；下水時間、浪板類型、心得、影片和照片都可不填。有選檔案時，先直接上傳到 R2，再儲存紀錄；存好會回首頁。 |
| 回看、編輯、刪除 | 詳細頁有影片時可播放，有照片時可點縮圖看大圖。本人可修改日期、浪點、下水時間、評分、浪板、心得和照片，但編輯畫面不能替換影片。編輯時會帶出原本的地區和浪點，只有改選地區時才要重選浪點。刪除前會確認；刪除後也會移除這筆的分享設定。 |
| 首頁與日曆       | 首頁有最近三筆紀錄和統計摘要；日曆標示有紀錄的日期，點選可打開當日的紀錄。                                                                        |
| 地圖             | 顯示台灣浪點，依本人的紀錄標示是否造訪和次數。程式清單有 37 個浪點。                                                                              |
| 統計             | 顯示個人的衝浪次數、浪點數量、平均浪況評分、常去浪點與浪板使用次數。                                                                              |
| 好友             | 可用名字找浪友，搜尋結果不顯示電子郵件地址。可送出邀請，也可接受或拒絕收到的邀請；這種邀請被拒後無法再送。也可用下方的浪友邀請連結直接成為好友。目前不能移除好友或取消已送出的邀請。 |

## 自動浪況

- 新增或編輯時，「幾點下水（選填）」可選 00:00 到 23:00 的整點。選了就顯示該整點的浪高、週期、湧浪方向、風速和風向；沒選則整理當天 06:00–18:00 的資料，數值顯示範圍、方向顯示平均方向。滿潮和乾潮顯示當天有取得的時間，不限於選定時段。
- WaveShare 在新增時查詢並保存資料；修改日期、浪點、浪點座標或下水時間時重新查詢。只改評分、心得等其他內容不會重查，打開紀錄也不會即時更新。
- 有資料時，首頁最近紀錄和詳細頁會顯示自動浪況與來源。台灣當天的紀錄如已設定中央氣象署金鑰，就優先用氣象署資料，缺項由 Open-Meteo 補上；湧浪方向只取自 Open-Meteo。其他情況使用 Open-Meteo。Open-Meteo 的滿潮和乾潮時間是潮位模型的估算。
- 查不到的項目不顯示；整筆查不到也不影響儲存。舊紀錄不會自動補上浪況。自動浪況與自己給的星等分開，不會改變評分。

## 分享圖卡

圖卡是可用於 IG 限時動態或 LINE 的直式 PNG 圖片（1080 × 1920）：

- **衝浪紀錄：** 本人可在自己的紀錄詳細頁按「分享圖卡」。圖卡顯示日期、浪點、浪況評分和浪板類型；查看好友分享的紀錄時沒有這個按鈕。
- **我的浪點：** 在地圖頁按「分享圖卡」，可把自己的造訪進度做成圖片。只計入清單上的 37 個浪點，同一浪點去多次也只算一個，並顯示各地區的進度。

圖卡可先預覽，再按「下載圖片」；支援直接分享圖片的瀏覽器也會顯示「分享圖片」。圖卡不含心得、附上的照片或影片，也不含連回紀錄的網址。把圖卡傳出去不會開放日誌權限，但收件人可保留或轉傳圖片，站內不能收回已送出的圖卡。

## 用連結邀請浪友

- 在「浪友」頁的「邀請浪友」按「取得邀請連結」，再按「複製邀請連結」。同一帳號取得的是同一條可重複使用的連結，可貼到 IG 或 LINE；拿到連結並登入的人可以加入，不需要你再同意。不希望陌生人加入，就只把連結傳給想邀請的人。
- 對方開啟邀請頁後，已登入可按「加入浪友」；未登入可按「使用 Google 登入並加入浪友」。WaveShare 會記住這次邀請，完成 Google 登入後直接加入，並回到浪友頁。不會因為打開連結就自動登入或加入。
- 未登入且用 IG 或 LINE 內的瀏覽器開啟時，請點右上角選單（Android 是「⋮」，iPhone 等其他裝置是「•••」），選擇用 Safari 或 Chrome 開啟，也可以複製連結後貼到瀏覽器。LINE 會先嘗試用外部瀏覽器開啟；沒跳出去時再用選單或複製連結。
- 自己不能接受自己的連結，無效連結也無法加入。雙方已是好友時不會重複新增；若原本有待處理或已拒絕的邀請，經由連結加入後會成為好友。成為好友不會自動分享任何紀錄。

## 好友分享與隱私

**每筆紀錄預設只給本人看。** 本人在詳細頁「分享給好友」勾選已接受邀請的好友並儲存，只會分享這一筆。對方從「好友分享給我的紀錄」可找到它，只能查看，不能編輯、刪除或更改分享設定（[PR #13](https://github.com/ChristingChang/waveshare/pull/13)）。

每次向 WaveShare 開啟影片（`/api/videos/<紀錄編號>`）或照片（`/api/photos/<照片編號>`）時，網站會確認是紀錄本人，或仍是好友而且有被選中，才提供 15 分鐘有效的 R2 觀看連結。取消勾選並儲存後，對方不能再開啟紀錄或向 WaveShare 取得新連結，但先前拿到的 R2 連結在到期前仍可能有效。

Cloudflare 的 R2 公開存取必須關閉，舊的公開網址才會失效。舊 Manus Forge 影片通過 WaveShare 的檢查後會開啟原網址；原網址本身是否公開，未確認。

## 影片與照片

| 規則       | 現況                                                                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 支援格式   | 只接受申報為 MP4、MOV 或 WebM 的影片；不掃描影片內容。                                                                                                                 |
| 大小       | 單檔最多 100 MiB，由瀏覽器直接傳到 R2，不受 Vercel 約 4.5 MB 的請求大小限制。                                                                                          |
| 次數       | 每位浪友在任意連續 24 小時內最多申請 10 次上傳；沒傳完也算。達上限時畫面會提示稍後再試。                                                                               |
| 播放       | 影片播放出錯時，播放器會自動重新取得連結一次，並回到原來的位置。上傳網址的 10 分鐘期限與播放無關。 |
| 刪除與清理 | 刪除紀錄時，若沒有其他紀錄在用，會嘗試刪除 R2 影片；失敗不阻擋日誌刪除。管理者可另外啟用每日清理，處理超過 24 小時仍沒存成紀錄的上傳。舊 Forge 影片不會自動刪除或搬遷。 |

新增紀錄時，送出影片會先顯示準備中，再顯示上傳百分比與進度條。影片傳完會顯示「影片已上傳，正在處理照片並儲存紀錄…」，此時日誌還沒存好。若只選影片、沒選照片，網站會在上傳影片的同時嘗試擷取一張畫面，等影片成功上傳後才上傳這張照片；擷取或上傳這張自動照片失敗，仍可存下影片和紀錄。影片上傳失敗會顯示提示，不會建立紀錄。

影片不會壓縮或轉檔，能否播放仍取決於瀏覽器與影片編碼。

照片每筆最多 10 張、每張最多 20 MiB，可選 JPG、PNG 或 HEIC／HEIF。瀏覽器會先把 HEIC／HEIF 轉成 JPG，再直接上傳到 R2；轉換後也不能超過大小上限。每個帳號在任意連續 24 小時內最多申請 100 次照片上傳，與影片分開計算。編輯可新增或移除照片；移除照片或刪除紀錄後，網站會嘗試清掉沒有其他紀錄使用的照片檔（[PR #14](https://github.com/ChristingChang/waveshare/pull/14)）。

新增或編輯紀錄時，照片傳不上去會依情況提示，例如照片功能尚未啟用、超過上傳次數，或傳檔失敗，而不是一律請你檢查網路。如果提示缺少照片資料表，請聯絡網站管理員。

## 目前不在範圍

- 未提供公開的日誌連結或好友動態牆；分享圖卡不會公開原紀錄。
- 同行夥伴只有預留資料結構，還沒有可用的標記功能。
- 舊資料是否搬遷、用戶如何接續舊帳號，見[架構決策紀錄](architecture-decisions.md)。
