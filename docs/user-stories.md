# WaveShare 使用者故事與驗收條件

每則說明「誰想做什麼、為什麼」，以及怎麼驗收。**現況**指編寫時的主分支。核取方塊是驗收項目，不是通過紀錄。[回文件首頁](README.md)

## 登入與帳號

### US-01｜登入我的日誌（現況）

身為浪友，我想用自己的帳號登入，方便回到個人日誌。

- [ ] 未登入時開啟日誌頁，被導往 Google 登入，且不顯示紀錄內容。
- [ ] 登入狀態仍有效時，可直接開啟自己的日誌，不會再要求授權。

### US-04｜使用 Google 帳號登入（現況）

身為浪友，我想用熟悉的 Google 帳號登入，不用另外開 Manus 或 GitHub 帳號。

- [ ] 未登入時開啟 WaveShare，會自動前往 Google 登入與授權；成功後回到首頁。
- [ ] 取消授權或收到無效的登入回應時，不會登入 WaveShare。
- [ ] 用同一個 Google 帳號再次登入，仍能看到自己的紀錄。
- [ ] 舊 Manus 使用者第一次用 Google 登入時，即使電子郵件相同，也不會自動取得舊日誌或好友。

### US-05｜資料存在 TiDB Cloud（現況）

身為網站維護者，我想確認部署時設定的 TiDB Cloud 能保存日誌，讓浪友下次登入時仍能回看。

- [ ] 在已建立資料表的測試環境，完成 Google 登入，新增一筆帶影片的紀錄，再重新登入確認紀錄仍能開啟。
- [ ] 修改心得後重新整理，仍能讀到新內容。
- [ ] 若另外安排搬遷舊資料，須核對筆數、擁有者、好友關聯及舊影片能否播放；設定 TiDB Cloud 不會自動搬資料。

## 記錄與回顧

### US-10｜新增一筆衝浪紀錄（現況）

身為浪友，我想記下當天的浪況，有影片或照片時再附上，好在日後回顧。

- [ ] 選日期、浪點與 1 至 5 顆星的評分；影片、照片、浪板與心得留空仍可儲存。儲存後可在相應日期的日曆找到該筆紀錄；沒附影片時，詳細頁不顯示播放器。
- [ ] 沒選浪點不能完成儲存；有附影片或照片但上傳失敗時，不會建立紀錄。

### US-13｜用私人照片記下這趟衝浪（現況）

身為浪友，我想在紀錄附上照片，即使沒拍影片也能回看當天的浪況。

- [ ] 不附影片也能儲存照片；在詳細頁點照片縮圖可看大圖。
- [ ] 可選 JPG、PNG 或 HEIC／HEIF，每張不超過 20 MiB；HEIC／HEIF 會在上傳前轉成 JPG。
- [ ] 新增及編輯時，每筆最多 10 張；編輯可新增或移除照片，保留的照片與新照片合計不能超過上限。
- [ ] 只有本人與這筆紀錄指定的好友能開啟照片網址（`/api/photos/<照片編號>`）；未登入的人、未被選中的好友都看不到。

### US-11｜不必把影片壓到很小（現況）

身為浪友，我想直接上傳普通的手機影片，不必先把它壓到 Vercel 的請求上限以下。

- [ ] 在已設定 R2 的測試站，上傳一支 50 MB、瀏覽器可播放的 MP4，儲存後能從詳細頁播放。
- [ ] 空檔、不支援的格式或超過 100 MiB 的影片不能開始上傳。若在上傳網址到期後才開始傳輸，不能用該網址完成儲存。

### US-12｜限制上傳申請（現況）

身為網站維護者，我想限制每個帳號的上傳申請次數，以減少濫用。

- [ ] 同一帳號在任意連續 24 小時內可以申請 10 次；放棄上傳也會計入。
- [ ] 第 11 次申請被擋下並提示已達上限；另一個帳號的次數不受影響。

### US-14｜更正已存的日誌（現況）

身為浪友，我想更正記錯的浪點或評分，不必重新上傳影片。

- [ ] 從自己的紀錄開啟編輯，畫面已選好原本的地區和浪點；只改評分就儲存，不會出現「請輸入浪點名稱」，重新整理後浪點不變。
- [ ] 改選另一個地區時浪點會清空，選好新浪點並儲存後，詳細頁顯示新資料。
- [ ] 現有影片仍相同；編輯畫面沒有更換影片的功能。

### US-15｜刪除不想保留的紀錄（現況）

身為浪友，我想移除一筆紀錄，讓它不再出現在自己的日誌。

- [ ] 按取消時資料不變；確認刪除後，該日誌不再出現在日曆或統計。
- [ ] 刪除紀錄也會移除它的分享設定與附上的照片。沒有其他紀錄使用的 R2 影片或照片，系統會嘗試刪除檔案；舊 Forge 影片不隨日誌刪除。

### US-17｜清理沒存成紀錄的影片（現況，選用）

身為網站維護者，我想清理沒有日誌引用的舊上傳，避免多付儲存費。

- [ ] 啟用每日清理後，申請超過 24 小時且未被引用的 R2 上傳會被處理；仍有引用、未到時限和舊 Forge 影片都保留。
- [ ] 未啟用或請求未授權時不清理；刪檔出錯時保留上傳申請，供下次重試。

### US-20｜按日期、浪點或浪板回顧（現況）

身為浪友，我想用日曆、地圖及統計回顧，方便找到某趟衝浪或比較自己的習慣。

- [ ] 在不同日期新增兩筆同浪點的紀錄，切換月份後可以找到各自的日期和詳細頁。
- [ ] 地圖顯示該浪點已造訪兩次，統計頁反映兩筆紀錄及有填寫的浪板類型；別人的紀錄不計入。

## 好友與隱私

### US-31｜加常一起衝浪的人為好友（現況）

身為浪友，我想搜尋並邀請認識的浪友，方便在好友列表找到對方。

- [ ] A 用名字找到 B；搜尋結果不顯示電子郵件地址，也不能用地址搜尋。
- [ ] A 送出邀請後，只有 B 的待處理清單顯示這筆邀請。
- [ ] 接受後雙方都出現在彼此的好友清單。拒絕時不成為好友，且現況不允許再送同一組的邀請。

### US-40｜只有我能管理我的日誌（現況）

身為紀錄擁有者，我希望只有我能修改、刪除或決定要跟誰分享我的紀錄。

- [ ] 用兩個已成為好友的測試帳號確認：A 分享一筆紀錄後，B 看不到編輯、刪除或分享設定。
- [ ] 若 B 嘗試修改、刪除或變更 A 的分享設定，A 的資料保持原樣，不以畫面是否報錯判斷。

### US-43｜只有我和指定好友能播放我的影片（現況）

身為浪友，我想讓影片和紀錄遵守相同的分享規則，才放心上傳。

- [ ] 本人和這筆紀錄指定的好友在詳細頁都可以播放影片。
- [ ] 把影片網址（`/api/videos/<紀錄編號>`）貼到未登入的視窗，不能播放，並提示請先登入。
- [ ] 用未獲分享的帳號（即使已是好友）打開同一個影片網址，不能播放，並顯示找不到影片。
- [ ] Cloudflare 關閉公開存取後，舊的 `r2.dev` 或自訂網域影片網址不能播放。
- [ ] 本人暫停超過 15 分鐘後再按播放，影片仍能從原處接著播。

### US-51｜指定誰能看我分享的日誌（現況）

身為浪友，我想選擇哪些好友可以看某筆紀錄，而不是讓所有知道網址的人都能看。

- [ ] 新紀錄預設不分享。本人在詳細頁「分享給好友」勾選已接受邀請的好友，再按「儲存分享設定」；只會分享這一筆。
- [ ] 被選中的好友能從「好友分享給我的紀錄」打開詳細頁，看見是誰分享的，並查看紀錄及附上的影片和照片；未被選中的好友就算知道網址也看不到。
- [ ] 取消勾選並儲存後，對方重新開啟詳細頁或用 WaveShare 的影片、照片網址都會被擋下。先前已取得的 R2 觀看連結仍可能在到期前使用（有效期 15 分鐘）。
